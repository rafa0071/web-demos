# Web demos

Ten small, working web apps and sites. Each one is a single HTML file with no build step or dependencies. All brands and data are fictional.

**Live gallery:** https://rafa0071.github.io/web-demos/

| Demo | What it shows |
| --- | --- |
| [Sales dashboard](https://rafa0071.github.io/web-demos/sales-dashboard/) | KPI cards, SVG line and donut charts with tooltips, sortable table, date-range switch |
| [Restaurant website](https://rafa0071.github.io/web-demos/restaurant/) | Menu tabs, reservation form with validation and opening-hour aware time slots |
| [Online store](https://rafa0071.github.io/web-demos/shop/) | Filters, sorting, color variants, slide-out cart saved in localStorage |
| [Kanban board](https://rafa0071.github.io/web-demos/kanban/) | Drag and drop, create/edit dialog, filters, search, progress |
| [Invoice generator](https://rafa0071.github.io/web-demos/invoice/) | Editable line items, tax/discount, currencies, print-to-PDF, JSON export |
| [Real-estate listings](https://rafa0071.github.io/web-demos/real-estate/) | Search filters, favorites, mortgage calculator |
| [Booking flow](https://rafa0071.github.io/web-demos/booking/) | Multi-step booking with calendar, time slots and .ics download |
| [Budget tracker](https://rafa0071.github.io/web-demos/budget/) | Monthly income/spending, category chart, budget limits, CSV export |
| [Weather app](https://rafa0071.github.io/web-demos/weather/) | Live data from the Open-Meteo API, city search, °C/°F |
| [SaaS landing page](https://rafa0071.github.io/web-demos/saas-landing/) | Hero UI mock, scroll animations, counters, pricing toggle, FAQ |

## Run locally

Open any `index.html` in a browser, or serve the folder with any static server.
